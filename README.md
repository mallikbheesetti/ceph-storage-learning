# Ceph Storage Learning Program - Red Hat Certification Path

A structured learning path for Ceph Storage from zero to Red Hat Certified Specialist level, aligned to the official **EX260** exam objectives.

## Certification Target

| Item | Detail |
|------|--------|
| Certification | Red Hat Certified Specialist in Ceph Cloud Storage |
| Exam | **EX260** - performance-based, 3 hours |
| Prerequisite | RHCSA (EX200) or equivalent experience |
| Recommended training | CL260 - Cloud Storage with Red Hat Ceph Storage |
| RHCA credit | Counts as one of three specialist exams toward RHCA (requires RHCE) |

See [Certification Path](certification/CERTIFICATION_PATH.md) for the full requirements, objective mapping, and exam-day checklist.

## Program Goals
- Build strong foundations of distributed storage and Ceph architecture
- Learn day-to-day usage, configuration, administration, maintenance/management, and security
- Practice with labs in virtualized environments
- Track progress systematically against EX260 objectives
- Validate readiness with timed mock exams

## Getting Started
1. Read the [certification path](certification/CERTIFICATION_PATH.md) and [learning plan](notes/learning-plan.md)
2. Set up your lab environment (VMs/containers)
3. Follow the weekly plan and mark progress
4. Complete the hands-on labs after each module
5. Take the [mock exams](certification/MOCK_EXAMS.md) under timed conditions
6. Score 85%+ twice on the full mock before booking EX260
