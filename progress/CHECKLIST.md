# Master Checklist - EX260 Certification Track

## Foundations
- [ ] Understand distributed storage concepts
- [ ] Know Ceph components and their roles
- [ ] Understand RADOS
- [ ] Understand CRUSH and PGs
- [ ] Know difference between RBD/CephFS/RGW

## Basic Usage
- [ ] Create and manage RBD images
- [ ] Mount and use CephFS
- [ ] Create RGW users and use S3/Swift APIs
- [ ] Use basic ceph CLI tools
- [ ] Understand pools and applications

## Configuration
- [ ] Understand config precedence
- [ ] Read/write ceph.conf
- [ ] Use ceph config CLI
- [ ] Configure networks
- [ ] Manage keyrings

## Administration
- [ ] Monitor cluster health
- [ ] Manage MONs/OSDs
- [ ] Create/manage replicated and erasure-coded pools
- [ ] Manage users and auth (CephX)
- [ ] Understand PG states
- [ ] Work with CRUSH
- [ ] Configure PG autoscaling

## Maintenance & Management
- [ ] Add/remove OSDs, MONs, MGRs
- [ ] Handle failures and recovery
- [ ] Understand scrubbing
- [ ] Plan upgrades
- [ ] Backup and restore data
- [ ] Troubleshoot common issues

## Security
- [ ] Implement CephX properly
- [ ] Apply least privilege
- [ ] Secure networks
- [ ] Configure RGW securely (TLS)
- [ ] Follow hardening checklist

## EX260 Objective Coverage
- [ ] Install a containerized Ceph cluster and modify installer files
- [ ] Add MON and OSD nodes to an existing cluster
- [ ] Replicated pools, namespaces, erasure-coded pools and profiles
- [ ] CephX users with restricted MON/OSD/pool/namespace access
- [ ] Manage OSDs with ceph-volume
- [ ] RBD images, snapshots, clones, mirrors, import/export
- [ ] RGW deployment, S3, Swift, multisite, NFS export, TLS
- [ ] CephFS creation, persistent mount, quotas, snapshots
- [ ] CRUSH bucket hierarchy, PG remap and redistribution
- [ ] MON/OSD maps and OSD storage limits
- [ ] Cluster status and OSD/MON troubleshooting
- [ ] Network tuning, scrub/deep-scrub control, recovery/rebalance, RAM vs I/O
- [ ] RGW debugging and RBD client tuning
- [ ] Glance and Cinder integration

- [ ] Have personal notes/cheatsheet
